About LearnDjango

LearnDjango is a web application designed to help users create and manage blog posts efficiently. Built using the Django framework, it provides a robust and scalable platform for blogging enthusiasts.

  • Overview
  • Core Technologies
  • Features

Overview

LearnDjango is a blogging platform that allows users to register, log in, and create posts. It also includes features like user profiles, password management, and pagination for browsing posts.

Core Technologies

  • Python 3.10
  • Django 4.2
  • Bootstrap 4
  • SQLite (default database)

Features

  • User authentication (registration, login, logout)
  • Profile management with profile pictures
  • CRUD operations for blog posts
  • Pagination for posts
  • Responsive design using Bootstrap

Setup

To set up the project locally, follow these steps:

  1. Clone the repository: git clone https://github.com/your-repo/learnDjango.git
  2. Navigate to the project directory: cd learnDjango
  3. Create a virtual environment: python3 -m venv venv
  4. Activate the virtual environment:
    • On macOS/Linux: source venv/bin/activate
    • On Windows: venv\Scripts\activate
  5. Install dependencies: pip install -r requirements.txt
  6. Run the development server: python manage.py runserver
